# ROADMAP

## 完了

- [x] **v0** —— 6×6グリッド、8構成の全数評価、Q学習
- [x] **v1** —— 10×10、狭い通路とハザードで課題を難しくする
- [x] **v1-検証** —— ランダムマップ48枚での大規模再検証

## 次

- [ ] **難しいマップの層を厚くする**
      壁・ハザードの比率を上げたマップを重点的に生成し、
      「環境が厳しいほど良い部品の価値が上がる」を確定させる（現状n=4で弱い）

- [ ] **v2：遺伝的アルゴリズム（GA）の導入**
      - 部品の種類・選択肢を増やし、全数評価が不可能な規模にする
      - 選抜 → 交叉 → 突然変異で世代を回す
      - 世代ごとの最高適応度・遺伝子の分布の推移を可視化
      - 狙い：**環境ごとに進化が別の答えへ収束する様子**を見せる
      - （組み合わせが少ないうちはGAは不要。全数評価が無理になって初めて導入する）

- [ ] **v3：物理シミュレーションへ**
      - Gymnasium + Stable-Baselines3（PPO/SAC）+ PyBullet
      - 抽象パラメータではなく、実際の脚の長さ・モータートルク・センサーノイズを身体パラメータに
      - 離散制御 → 連続制御
      - 計算コストが跳ね上がるので、個体数・世代数は要調整

- [ ] **v4：創発を狙う**
      - 身体の自由度をさらに開放
      - MAP-Elites などで多様な解を保ちながら探索
      - 「誰も設計していない解」が出るのを観察する
      - 形状（連続的な形）を入れるのは最後
