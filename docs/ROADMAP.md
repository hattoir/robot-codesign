# ROADMAP

## 完了

- [x] **v0** —— 6×6グリッド、8構成の全数評価、Q学習
- [x] **v1** —— 10×10、狭い通路とハザードで課題を難しくする
- [x] **v1-検証** —— ランダムマップ48枚での大規模再検証
- [x] **v2：遺伝的アルゴリズム（GA）の導入**
      6部品×3択＝729通りに拡張。GA（トーナメント選択・一様交叉・突然変異・
      エリート保存）を実装し、全数評価の正解と突き合わせて検証
- [x] **v2.5：「学習しやすさ」を適応度に入れる**
      最終性能だけでなく学習曲線の立ち上がりを評価軸に加える。
      学習プロファイルは40件 → 60件に拡張済み
- [x] **v3：役割ごとの部品選定（役割別GA）**
      3つの役割それぞれでタスク報酬Rと適応度Fを変え、役割別に構成を選抜

## 次

- [ ] **難しいマップの層を厚くする**
      壁・ハザードの比率を上げたマップを重点的に生成し、
      「環境が厳しいほど良い部品の価値が上がる」を確定させる（現状n=4で弱い）

- [ ] **役割別GAの詰め**
      - 省エネ役割を速度重視と区別できるよう再設計する
      - 役割別GAの試行回数を増やす（特にsafety）
      - 複数マップで回し、マップ依存でないことを確認する

- [ ] **v4：物理シミュレーションへ**
      - Gymnasium + Stable-Baselines3（PPO/SAC）+ PyBullet
      - 抽象パラメータではなく、実際の脚の長さ・モータートルク・センサーノイズを身体パラメータに
      - 離散制御 → 連続制御
      - 計算コストが跳ね上がるので、個体数・世代数は要調整

- [ ] **v5：創発を狙う**
      - 身体の自由度をさらに開放
      - MAP-Elites などで多様な解を保ちながら探索
      - 「誰も設計していない解」が出るのを観察する
      - 形状（連続的な形）を入れるのは最後
